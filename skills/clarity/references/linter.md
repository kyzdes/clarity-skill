# LINTER — спецификация линтера чёткой и ёмкой речи

> Автопроверки для `method.md`. Архитектура — по образцу Главреда, как её описывают сами авторы (✅ отчёт 05): **L1 — механика** (словарь/regex/морфология, дёшево, много ложных срабатываний) → **L2 — агентная проверка** (смысл и контекст) → **L3 — показатели текста целиком**. Балл — гигиена, не качество: «Помимо отсутствия мусора в тексте должен быть сильный синтаксис, стройная структура, убедительные аргументы... эта работа всё ещё остаётся на редакторе» (Ильяхов).

## 0. Принципы

1. **Каждое срабатывание L1 — «кандидат», не «ошибка»** (селективное правило стоп-слов ✅). Autofix запрещён; только suggestions.
2. **Severity:** `blocker` (ломает смысл/честность) · `warning` (вероятный мусор) · `info` (наблюдение, прокси-метрика).
3. **Ручки из METHOD §2 меняют пороги:** при «терминологичной» ручке А словари канцелярита не применяются к терминам предметной области (передаётся whitelist); при цели «зафиксировать без двусмысленности» правила L1-16 (пассив) и L1-17 (отрицания) понижаются до info.
4. **Баллы между версиями словарей несравнимы** (✅ урок Главреда) — в отчёте указывается версия словаря.
5. Единица проверки — предложение; агрегация — абзац и текст.

## 2. Уровень L2 — агентная проверка (смысл и контекст)

| ID | Проверка | Инструкция агенту |
|---|---|---|
| L2-01 | **Субъектность.** Для каждого срабатывания L1-10/11: есть ли живой деятель, которого можно поставить в подлежащее? Если деятеля в реальности нет (процесс безличен) — снять флаг. | Переписать кандидата в «кто — сделал — что»; если стало хуже/неверно — false positive |
| L2-02 | **Селективность стоп-слов.** Для каждого L1-20/21/22: несёт ли слово информацию (модальность, вежливость, юр. оговорку)? | Тест Ильяхова «несёт ли новую информацию» + тест Пинкера «choice or tic»; тик → замена точной квалификацией |
| L2-03 | **Пассив по причине.** Для L1-16: деятель неизвестен/неважен? тема-рема требует объекта в теме? | Если причина есть — снять; если пассив прячет ответственного — blocker |
| L2-04 | **Known→new.** Пройти по абзацу: каждое предложение открывается уже известным? тип связи с предыдущим называем (сходство/последовательность/причина)? | Дыра связи → переставить или добавить коннектор |
| L2-05 | **Проклятие знания.** Смоделировать читателя из целевой аудитории: какие чанки не распакованы, какие шаги рассуждения пропущены? | Список «мест, где читатель отвалится», с правками |
| L2-06 | **Тон-чек (полуавто).** Прочитать текст «голосом»: где звучит варварски (правило №6 Оруэлла) или пересушено (terse Уильямса, «огрубляй» из критики инфостиля)? | Вернуть воздух; финальное слово — человек |
| L2-07 | **Честность.** Каждое число/сильное утверждение — с опорой? Ничего из чёрного списка VERDICTS III не процитировано? | blocker при нарушении |

## 3. Уровень L3 — показатели текста целиком

- Доля предложений, прошедших тест 5–8 слов (цель: >80% для рабочей прозы).
- Плотность флагов L1 на 1000 слов до/после правки (динамика важнее абсолюта).
- Максимальная глубина вложения и длина падежной цепочки по тексту (цель: ≤1 и ≤2).
- Число намеренных повторов тезиса (1–2 — норма; 0 — проверить финал; 3+ — перебор).
- Доля мета-дискурса (предложения о тексте vs о предмете).

## 4. Выходной формат

```
[L1-12][warning] предложение 14: «системы обеспечения повышения эффективности» — цепочка из 4 родительных.
  Кандидат: «системы, которые повышают эффективность» / «системы для роста эффективности»
[L2-02][снято] «предположительно» в предложении 9 — несёт модальность (оценка, не замер). Оставить.
Итог: 3 blocker · 12 warning · 9 info · словарь v0.1 · pass=false
```

`pass` = ни одного blocker. Балл/количество флагов НЕ репортится как «качество текста».

## Приложение A. Словари (v0.1)

**A.1 Абстрактные подлежащие-маркеры:** осуществление, проведение, обеспечение, реализация, использование, применение, выполнение, внедрение, функционирование, наличие, отсутствие, необходимость, возможность (в роли подлежащего).

**A.2 Пустые глаголы:** имеется, имеются, дается, даются, осуществляется/-ют, производится/-ят, обеспечивается/-ют, реализуется/-ют, проводится/-ят, является/-ются (связка при живом глаголе). *(Ядро ✅ Чуковский: имеется, дается; остальное — расширение ⚪.)*

**A.3 Отымённые предлоги:** ✅-ядро: с позиций, в деле, в части, в силу, при наличии. Расширение ⚪: в целях, в рамках, по линии, в условиях, в ходе, в процессе, по вопросу, в отношении, по причине, в связи с (при простой альтернативе). Замены: чтобы, о, из-за, при, во время.

**A.4 Отрицания→позитив (suggestions):** не часто→редко · не очень→мало, слабо · не заметил→пропустил · не аккуратен→небрежен · не разрешать→запрещать · не помнить→забыть. *(Форма ✅ Strunk/Williams; пары — адаптация.)*

**A.5 Хеджи-тики (RU-адаптация каталога Пинкера ✅):** практически, по-видимому, сравнительно, довольно, отчасти, частично, преимущественно, предположительно, скорее, относительно, так сказать, несколько, в некоторой степени, в известном смысле, как бы, в целом, по сути, в принципе, скажем так, я бы сказал.

**A.6 Казённое→живое («Словесная алгебра» ✅ Галь + штампы):** следовательно→значит · действительно→в самом деле, впрямь · заблаговременно→заранее, загодя · направлялся→шёл · произошло→случилось · лично→сам · обнаружил→увидел, заметил, нашёл. Штампы (⚪): в настоящее время→сейчас · в кратчайшие сроки→быстро, к <дате> · оказать содействие→помочь · довести до сведения→сообщить · принять меры→сделать <что>.

**A.7 AI-slop RU (наследие copy-engine):** раскрыть потенциал, бесшовный, экосистема (вне биологии), синергия, в современном мире, в эпоху цифровизации, играет ключевую роль, является неотъемлемой частью, стоит отметить, давайте разберёмся, «не X, а Y» как повторяющийся тик.

**A.8 Заимствования-понты (замены):** пролонгировать→продлить · транспарентный→прозрачный · имплементировать→внедрить · челлендж→задача, вызов · экспертиза (в знач. «опыт»)→опыт · компетенции (мн.)→навыки. *(Термины предметной области — в whitelist.)*

**A.9 Плеоназмы — ЧЕРНОВИК ⚠️ (источник «Розенталь §141» дважды не подтвердился; сверить с прямым текстом до повышения severity):** период времени, совместное сотрудничество, свободная вакансия, главный приоритет, предварительный анонс, впервые дебютировал, целиком и полностью, окончательный итог.
